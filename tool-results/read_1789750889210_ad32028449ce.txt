   212→  <section class="faqBlock" aria-labelledby="faqTitle">
   213→    <h2 class="sectitle" id="faqTitle">Frequently asked questions</h2>
   214→    <div class="faqlist">
   215→      <details class="faq">
   216→        <summary>Is anonshare really end-to-end encrypted?</summary>
   217→        <p>Yes. Everything you type is encrypted with AES-GCM in your browser before it is sent anywhere. The relay only ever stores and forwards sealed bytes it cannot read. See <a href="security.html">how the encryption works</a> for the full threat model.</p>
   218→      </details>
   219→      <details class="faq">
   220→        <summary>Do I need to sign up or create an account?</summary>
   221→        <p>No. There is no sign-up, no email, and no account of any kind. Pick a display name and start typing.</p>
   222→      </details>
   223→      <details class="faq">
   224→        <summary>How long does a room last?</summary>
   225→        <p>You choose when you create it: 10 minutes, 1 hour, or 24 hours after everyone has left. The owner can also delete the room immediately, which erases it for everybody.</p>
   226→      </details>
   227→      <details class="faq">
   228→        <summary>What happens if I lose the room code or password?</summary>
   229→        <p>The room becomes unreachable. There is no password reset and no server-side backdoor, since the key is derived only from the code and password inside your browser.</p>
   230→      </details>
   231→      <details class="faq">
   232→        <summary>Can I use anonshare for code, not just plain text?</summary>
   233→        <p>Yes. Rooms support multiple files with syntax highlighting for many languages, plus live chat alongside the editor.</p>
   234→      </details>
   235→      <details class="faq">
   236→        <summary>Does anonshare track me?</summary>
   237→        <p>No cookies and no personal data are collected. The marketing site uses cookieless, privacy-friendly analytics that cannot identify or follow you. See the <a href="privacy.html">privacy policy</a> for details.</p>
   238→      </details>
   239→      <details class="faq">
   240→        <summary>Can I use anonshare on Android and mobile phones?</summary>
   241→        <p>Yes. anonshare is fully responsive and tailored for Android and mobile browsers. It includes a thumb-friendly bottom navigation bar, quick syntax keys bar for braces, semicolons, quotes and indentation, full drawer sheets, and native file uploads up to 25MB directly from your phone's storage.</p>
   242→      </details>
   243→      <details class="faq">
   244→        <summary>Can I run and compile code inside anonshare?</summary>
   245→        <p>Yes. With the built-in Runner (Ctrl+Enter or mobile Run button), you can execute Python, JavaScript, C, C++, Rust, Go, Java, Bash, and more. Code is compiled and run inside an isolated Linux Bubblewrap sandbox with zero outbound network access and strict 256MB RAM caps.</p>
   246→      </details>
   247→      <details class="faq">
   248→        <summary>Can I share files with others in the room?</summary>
   249→        <p>Yes. You can upload and share files up to 25MB. Files are encrypted client-side in your browser with AES-GCM before upload, stored ephemerally in room memory or streamed via WebRTC DataChannels, and erased permanently when the room expires.</p>
   250→      </details>
   251→      <details class="faq">
   252→        <summary>Is voice chat recorded or stored?</summary>
   253→        <p>No. Voice chat connects room members directly peer-to-peer using WebRTC with DTLS-SRTP encryption. No voice audio is ever recorded, transcribed, or stored on any server.</p>
   254→      </details>
   255→      <details class="faq">
   256→        <summary>What happens if I lose my internet connection while I'm typing?</summary>
   257→        <p>Your edits keep working locally. An offline copy is kept in your browser, and everything syncs automatically the moment your connection comes back.</p>
   258→      </details>
   259→      <details class="faq">
   260→        <summary>Can I run my own relay instead of the default one?</summary>
   261→        <p>Yes. anonshare is <a href="https://github.com/AvishkarKedar/textshare" target="_blank" rel="noopener">open source</a>. You can deploy the relay yourself on Cloudflare Workers or your own VPS and point the app at it - see the GitHub repository for instructions.</p>
   262→      </details>
   263→      <details class="faq">
   264→        <summary>Is anonshare open source?</summary>
   265→        <p>Yes, the entire project - the editor, the relay, and the admin tools - is <a href="https://github.com/AvishkarKedar/textshare" target="_blank" rel="noopener">open source under the MIT licence on GitHub</a>.</p>
   266→      </details>
   267→      <details class="faq">
   268→        <summary>Is there a limit on room size?</summary>
   269→        <p>Each room supports up to 30 connections, live document history, and encrypted file sharing up to 25MB per file.</p>
   270→      </details>
