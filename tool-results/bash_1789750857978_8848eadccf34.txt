  <section class="faqBlock" aria-labelledby="faqTitle">
    <h2 class="sectitle" id="faqTitle">Frequently asked questions</h2>
    <div class="faqlist">
      <details class="faq">
        <summary>Is anonshare really end-to-end encrypted?</summary>
        <p>Yes. Everything you type is encrypted with AES-GCM in your browser before it is sent anywhere. The relay only ever stores and forwards sealed bytes it cannot read. See <a href="security.html">how the encryption works</a> for the full threat model.</p>
      </details>
      <details class="faq">
        <summary>Do I need to sign up or create an account?</summary>
        <p>No. There is no sign-up, no email, and no account of any kind. Pick a display name and start typing.</p>
      </details>
      <details class="faq">
        <summary>How long does a room last?</summary>
        <p>You choose when you create it: 10 minutes, 1 hour, or 24 hours after everyone has left. The owner can also delete the room immediately, which erases it for everybody.</p>
      </details>
      <details class="faq">
        <summary>What happens if I lose the room code or password?</summary>
        <p>The room becomes unreachable. There is no password reset and no server-side backdoor, since the key is derived only from the code and password inside your browser.</p>
      </details>
      <details class="faq">
        <summary>Can I use anonshare for code, not just plain text?</summary>
        <p>Yes. Rooms support multiple files with syntax highlighting for many languages, plus live chat alongside the editor.</p>
      </details>
      <details class="faq">
        <summary>Does anonshare track me?</summary>
        <p>No cookies and no personal data are collected. The marketing site uses cookieless, privacy-friendly analytics that cannot identify or follow you. See the <a href="privacy.html">privacy policy</a> for details.</p>
      </details>
      <details class="faq">
        <summary>Can I use anonshare on Android and mobile phones?</summary>
        <p>Yes. anonshare is fully responsive and tailored for Android and mobile browsers. It includes a thumb-friendly bottom navigation bar, quick syntax keys bar for braces, semicolons, quotes and indentation, full drawer sheets, and native file uploads up to 25MB directly from your phone's storage.</p>
      </details>
      <details class="faq">
        <summary>Can I run and compile code inside anonshare?</summary>
        <p>Yes. With the built-in Runner (Ctrl+Enter or mobile Run button), you can execute Python, JavaScript, C, C++, Rust, Go, Java, Bash, and more. Code is compiled and run inside an isolated Linux Bubblewrap sandbox with zero outbound network access and strict 256MB RAM caps.</p>
      </details>
      <details class="faq">
        <summary>Can I share files with others in the room?</summary>
        <p>Yes. You can upload and share files up to 25MB. Files are encrypted client-side in your browser with AES-GCM before upload, stored ephemerally in room memory or streamed via WebRTC DataChannels, and erased permanently when the room expires.</p>
      </details>
      <details class="faq">
        <summary>Is voice chat recorded or stored?</summary>
        <p>No. Voice chat connects room members directly peer-to-peer using WebRTC with DTLS-SRTP encryption. No voice audio is ever recorded, transcribed, or stored on any server.</p>
      </details>
      <details class="faq">
        <summary>What happens if I lose my internet connection while I'm typing?</summary>
        <p>Your edits keep working locally. An offline copy is kept in your browser, and everything syncs automatically the moment your connection comes back.</p>
      </details>
      <details class="faq">
        <summary>Can I run my own relay instead of the default one?</summary>
        <p>Yes. anonshare is <a href="https://github.com/AvishkarKedar/textshare" target="_blank" rel="noopener">open source</a>. You can deploy the relay yourself on Cloudflare Workers or your own VPS and point the app at it - see the GitHub repository for instructions.</p>
      </details>
      <details class="faq">
        <summary>Is anonshare open source?</summary>
        <p>Yes, the entire project - the editor, the relay, and the admin tools - is <a href="https://github.com/AvishkarKedar/textshare" target="_blank" rel="noopener">open source under the MIT licence on GitHub</a>.</p>
      </details>
      <details class="faq">
        <summary>Is there a limit on room size?</summary>
        <p>Each room supports up to 30 connections, live document history, and encrypted file sharing up to 25MB per file.</p>
      </details>
