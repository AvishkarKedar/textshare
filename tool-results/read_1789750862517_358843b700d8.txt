   213→  <section class="faqBlock" aria-labelledby="faqTitle">
   214→    <h2 class="sectitle" id="faqTitle">Frequently asked questions</h2>
   215→    <div class="faqlist">
   216→      <details class="faq">
   217→        <summary>Is anonshare really end-to-end encrypted?</summary>
   218→        <p>Yes. Everything you type is encrypted with AES-GCM in your browser before it is sent anywhere. The relay only ever stores and forwards sealed bytes it cannot read. See <a href="security.html">how the encryption works</a> for the full threat model.</p>
   219→      </details>
   220→      <details class="faq">
   221→        <summary>Do I need to sign up or create an account?</summary>
   222→        <p>No. There is no sign-up, no email, and no account of any kind. Pick a display name and start typing.</p>
   223→      </details>
   224→      <details class="faq">
   225→        <summary>How long does a room last?</summary>
   226→        <p>You choose when you create it: 10 minutes, 1 hour, or 24 hours after everyone has left. The owner can also delete the room immediately, which erases it for everybody.</p>
   227→      </details>
   228→      <details class="faq">
   229→        <summary>What happens if I lose the room code or password?</summary>
   230→        <p>The room becomes unreachable. There is no password reset and no server-side backdoor, since the key is derived only from the code and password inside your browser.</p>
   231→      </details>
   232→      <details class="faq">
   233→        <summary>Can I use anonshare for code, not just plain text?</summary>
   234→        <p>Yes. Rooms support multiple files with syntax highlighting for many languages, plus live chat alongside the editor.</p>
   235→      </details>
   236→      <details class="faq">
   237→        <summary>Does anonshare track me?</summary>
   238→        <p>No cookies and no personal data are collected. The marketing site uses cookieless, privacy-friendly analytics that cannot identify or follow you. See the <a href="privacy.html">privacy policy</a> for details.</p>
   239→      </details>
   240→      <details class="faq">
   241→        <summary>Can I use anonshare on Android and mobile phones?</summary>
   242→        <p>Yes. anonshare is fully responsive and tailored for Android and mobile browsers. It includes a thumb-friendly bottom navigation bar, quick syntax keys bar for braces, semicolons, quotes and indentation, full drawer sheets, and native file uploads up to 25MB directly from your phone's storage.</p>
   243→      </details>
   244→      <details class="faq">
   245→        <summary>Can I run and compile code inside anonshare?</summary>
   246→        <p>Yes. With the built-in Runner (Ctrl+Enter or mobile Run button), you can execute Python, JavaScript, C, C++, Rust, Go, Java, Bash, and more. Code is compiled and run inside an isolated Linux Bubblewrap sandbox with zero outbound network access and strict 256MB RAM caps.</p>
   247→      </details>
   248→      <details class="faq">
   249→        <summary>Can I share files with others in the room?</summary>
   250→        <p>Yes. You can upload and share files up to 25MB. Files are encrypted client-side in your browser with AES-GCM before upload, stored ephemerally in room memory or streamed via WebRTC DataChannels, and erased permanently when the room expires.</p>
   251→      </details>
   252→      <details class="faq">
   253→        <summary>Is voice chat recorded or stored?</summary>
   254→        <p>No. Voice chat connects room members directly peer-to-peer using WebRTC with DTLS-SRTP encryption. No voice audio is ever recorded, transcribed, or stored on any server.</p>
   255→      </details>
   256→      <details class="faq">
   257→        <summary>What happens if I lose my internet connection while I'm typing?</summary>
   258→        <p>Your edits keep working locally. An offline copy is kept in your browser, and everything syncs automatically the moment your connection comes back.</p>
   259→      </details>
   260→      <details class="faq">
   261→        <summary>Can I run my own relay instead of the default one?</summary>
   262→        <p>Yes. anonshare is <a href="https://github.com/AvishkarKedar/textshare" target="_blank" rel="noopener">open source</a>. You can deploy the relay yourself on Cloudflare Workers or your own VPS and point the app at it - see the GitHub repository for instructions.</p>
   263→      </details>
   264→      <details class="faq">
   265→        <summary>Is anonshare open source?</summary>
   266→        <p>Yes, the entire project - the editor, the relay, and the admin tools - is <a href="https://github.com/AvishkarKedar/textshare" target="_blank" rel="noopener">open source under the MIT licence on GitHub</a>.</p>
   267→      </details>
   268→      <details class="faq">
   269→        <summary>Is there a limit on room size?</summary>
   270→        <p>Each room supports up to 30 connections, live document history, and encrypted file sharing up to 25MB per file.</p>
   271→      </details>
